Project Name: Sales Performance Analysis and Profitability Reporting System.

Project Overview and Approach -

• Built an interactive Executive Sales & Profitability Dashboard on ~2,700 order records to track revenue, gross profit, Gross Profit margin, units sold, orders and COGS.
• Added calculated fields (Year, Month, Quarter) to the raw data, summarised it through named PivotTables, and presented the insights as KPI cards and linked charts: monthly revenue vs. profit trend, top 5 countries, channel share, region comparison and a country map.
• Slicers (Product Category, Country, Quarter) connected to every visual enable instant filtering.

Tools / Methods / Frameworks -

• Microsoft Excel: Tables, PivotTables, PivotCharts, Slicers (Report Connections), Map Chart.
• Formulas: YEAR, MONTH, TEXT, ROUNDUP.
• Techniques: data transformation, Top-N filtering, custom sorting, custom number formats (K), shape-based dashboard design, hyperlink navigation.

Result / Impact -

• Delivered a single-page, interactive dashboard that gives management a complete view of sales performance and profitability, covering revenue, gross profit, margin, volume sold, order count and cost of goods sold.
• Identified the top-performing countries, with the UK and Germany well ahead of the rest, and compared channel and regional contributions to show where revenue was concentrated.
• Added slicers so users can filter every KPI and chart at once by product category, country and quarter. This replaces static, manual reporting with a dynamic view that supports faster, data-driven decisions.
